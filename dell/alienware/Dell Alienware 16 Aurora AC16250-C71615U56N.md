Bu model güncel olarak kullandığım modeldir. Varsayılan olarak Intel Core i7 240H, RTX 5060, 16 GB Ram ve 1 tb SSD ile gelmektedir. Satın olmuş olduğum bu modelde varsayılan olarak Ubuntu indirilmiş olsa klavyenin FN tuşları yalnızca KDE Plasma ile düzgün çalışmaktadır. Copilot tuşunu remap etmek için [dotfiles](https://github.com/kayrakrh/dotfiles) reposuna bakabilirsiniz.

Bazı Linux dağıtımlarında ses kartı düzgün çalışmayabiliyor.

Linux deneyimi değerlendirmem
| Masaüstü | Puan (10 üzerinden) |
| - | - |
| KDE Plasma 6.0+ | 8 |
| GNOME | 7.5 |
| Diğer Masaüstü Ortamları | 7 |
